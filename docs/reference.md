# Visual & Architectural Reference Guide — Ayush Trivedi Portfolio

## 1. Core Visual Atmosphere
- **Color Identity**:
  - Ink Background: `#0A0A0A` / `#0C0C0C` with subtle warm radial illumination vignette
  - Drafting Surface / Panels: `#121212` / `#161616`
  - Architectural Gold Accent: `#D4A853` (used with strict restraint for coordinates, indices, active states)
  - Warm Chalk Primary Typography: `#F0EDE8`
  - Technical Notation / Secondary: `#8A8680`
  - Subtle Guide Rules & Grids: `#1F1F1F` / `#2A2A2A`

## 2. Spatial Composition & Architectural Language
- **Drafting Grid & Annotations**: Subtle vertical guide rules, technical coordinate marks (`LAT 28.4744° N · LON 77.5040° E`), index identifiers (`00` to `06`), and corner ticks.
- **Visual Depth**: Layered surface planes, z-depth perspective in the 3D spatial resume studio, subtle ambient occlusion shadows, and controlled lighting.
- **Typographic Scale**: Oversized editorial display typography (`Playfair Display`), crisp monospaced metadata (`JetBrains Mono`), and clean high-legibility body text (`Inter`).

## 3. Motion & Choreography
- Sequential entrance staging: Background $\rightarrow$ Grid lines $\rightarrow$ Technical metadata $\rightarrow$ Masked heading reveal $\rightarrow$ Narrative $\rightarrow$ CTAs.
- Masked line reveals through `overflow-hidden` clips with custom cubic-bezier easing (`[0.16, 1, 0.3, 1]`).
- Strict `prefers-reduced-motion` compliance across all interactive layers.
